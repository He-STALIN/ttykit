# Примеры кода и документация

## `Console` класс
> Как я и сказал выше, этот класс контроллирует события терминала
>
> Для начала использования, напиши
```python
from ttykit import Console

console = Console() # получаем экземпляр класс для последующего использования
```
> Последующие примеры кода для этого кода будут основываться на этом.
> 
> Этот класс может принимать 6 аргументов:
- `color_system` (str, optional)
    > Цветовая схема терминала. По умолчанию стоит "auto".
    >
    > Он может быть "standard", "256" или "truecolor". Если вы не знаете, какую цветовую схему использовать, оставьте "auto" для авто-определения.

- `width` (int)
    > Ширина терминала.
    >
    > Вы можете указать свою ширину терминала или оставить `None` для авто-определения текущей ширины терминала.

- `height` (int)
    > Высота терминала.
    >
    > Как и с `width`, вы можете поставить свою высоту или оставить `None` для авто-определения.

- `stderr` (bool)
    > Контролирует куда выводятся ошибки.
    > 
    > Если активно (`True`), будет отправлять ошибки в stdErr вместо stdOut, иначе в stdOut.

- `no_color` (bool)
    > Управляет цветом в этом терминале.
    >
    > Если активно, любые цвета (даже те, что вы вводите)Ю будут монохромными (черными и белыми) без других цветов.

- `force_terminal` (bool)
    > Если активно, библиотека не будет проверять терминал и и будет использовать коды в любой ситуации.

> итак, класс имеет на текущий момент 3 метода:

- `bell()`
    > Этот метод отправляет сигнал на проигрывание "колокольчика". Эквивалентно ANSI коду `\a`.
    >
    > Думаю, приводить к нему пример не требуется.

- `print(*args, sep, end, justify, fillchar)`
    > Выводит текст. Работает как обычный `print()`, но со своими особенностями.
    > 
    > Он принимает 5 агрументов:
    - `*args`
        > Просто ваша строка с текстом, которую хотите вывести.
    - `sep` (str)
        > Символ разделителя, если вы даете сразу несколько строк. По умолчанию это " " (пробел).
    - `end` (str)
        > Символ, который выведится в конце вывода. По умолчанию символ новой строки (`\n`).
    - `justify` (str)
        > Выравнивание текста. Может быть "left", "center" или "right". По умолчанию стоит "left".
    - `fillchar` (str)
        > Символ, которым заполняется свободное место в строке в терминале. Обычно это не нужно трогать, так как по умолчанию стоит " " (пробел).
    > Вот пример кода:
    ```python
    text = "Ваш какой-то текст для [green]вывода [/]"

    console.print(text, justify="left")
    ```
    > Да, вы могли заметить `[green]` и `[/]`
    > 
    > Это шаблоны для вставки цветов и стилей. Чтобы вставка работала, название должно быть в `[ ]`. О, и не забудьте добавить "[/]" в конце строки, иначе последующие символы продолжать использовать эту стилизацию.
    >
    > Кстати, в одном шаблоне (`[ ]`) вы можете использовать названия цвета и стиля одновременно.
    > 
    > Доступные цвета для вставки (те же, что и в [`Colors`](#colors-класс)): `black`, `red`, `green`, `yellow`, `blue`, `purple`, `cyan`, `white`, `dark_grey`, `light_red`, `light_green`, `light_yellow`, `light_blue`, `light_purple`, `light_cyan`, `light_white`
    >
    > Доступные стили (те же, что и в [`Styles`](#styles-класс)): `bold`, `dim`, `italic`, `underline`, `blink`, `rapid_blink`, `reverse`, `strikethrough`


- `input(prompt, password)`
    > Получает вписанный пользователем текст.
    >
    > Он принимает 2 аргумента:
    - `prompt` (str)
        > промпт (или же подсказку) для пользователя. Можете ничего не указывать (это опционально).
    - `password` (bool)
        > Если флаг активен, вписанная пользователем информация будет скрыта (выключает эхо символы).
        ```python
        input = console.input("некоторый промпт", password=True) # говорим мол "Эй, скрой символы"
        ```
    > Здесь вы так же можете использовать шаблоны для `prompt`.

## `Status` класс
> Этот класс показывает анимированный статус выполнения, пока ваш код выполняет полезную нагрузку
>
> Для начала использования, напишите
```python
from ttykit import Status
```
> Однако здесь есть 2 пути для реализации:
>
> 1. Создать один экземпляр для для всего вашего кода
```python
status_inst = Status()
```
> 2. Использовать контекстный менеджер для каждой задачи отдельно
```python
with Status() as status:
    ... # ваш код
```
> Окей, с реализацией закончили.
>
> Этот класс приминает 3 аргумента:
- `message` (str)
    > Название или небольшое описание выполняемой задачи. Просто для понимания "Что прямо сейчас выполняется?"
    >
    > Так же можете оставить пустым.

- `spinner` (str)
    > Спиннер анимированного статуса. По умолчанию стоит "bar"
    >
    > Доступные спиннеры: `bar`, `ball`, `dots`, `dots12`, `bouncingBar`, `points`, `wave`, `pulse`, `moon`, `clock`, `snake`, `line`, `box`, `arc`.
    >
    > Не знаете, что выбрать? Вы можете посмотреть анимации: выполни `python -m ttykit.spinner` в терминале

- `color` (str)
    > цвет выделения для аргумента `message`.
    >
    > Про доступные цвета я уже сказал выше в `Console.print()`
> Итак, давайте я опишу методы, а затем и примеры кода.
>
> Этот класс предоставляет 4 метода:
- `set_message(new_message)`
    > Заменяет старое сообщение на новое.
    >
    > полезно, если вы выбрали первую реализацию или используете один менеджер сразу для нескольких задач.
    >
    > Как аргумент он принимает строку.

- `set_state(state)`
    > Устанавливает статус выполнения кода.
    >
    > Чтобы его установить, вам потребуется `TaskState` (в этой же библиотеке)

- `pause()`
    > Ставит анимацию на паузу. Больше ничего (ваш код сможет выполняться и дальше).

- `resume()`
    > Возобновляет анимацию. Ничего более.

> Итак, мы дошли до примеров.
>
> Я покажу по одному примеру для каждой реализации
>
> Первый подход
```python
from ttykit import TaskState

with status as status:
    status.set_message("некоторая задача") # Устанавливаем название
    <ваш код>
    status.set_state(TaskState.SUCCESS) # Устанавливаем статус выполнения (успешно)

with status as status:
    status.set_message("2 некоторая задача")
    ...
```
> Здесь мы создаем из глобального экземпляра `Status()`
>
> Эта реализаци подходит вам, если вам важна опимизация потребления памяти вашим кодом.
>
> [`TaskState`](#taskstate-класс) это утилитарный класс, поэтому описан будет в конце.
>
> Второй подход
```python
from ttykit import TaskState

with Status("название задачиe", spinner="dots12") as status:
    <нагрузка>
    status.set_state(TaskState.SUCCESS)

with Status("unit name 2", spinner="dots12") as status:
    <нагрузка 2>
    status.set_state(TaskState.SUCCESS)
```
> Здесь мы создаем для каждого отдельно (через контекстный менеджер)
>
> Если потребление памяти не критично, используйте этот вариант (хотя этот класс пояти ничего не ест 😑)

## `Progress` класс
> Как я сказал выше, этот класс создает полосу прогресса в терминале
>
> Чтобы использовать, напишите
```python
from ttykit import Progress
```
> Здесь, как и в [`Status class`](#status-class), есть 2 пути реализации, но описывать их снова я не буду.
>
> Давайте посмотрим на аргументы, которые он принимает:
- `total` (int)
    > Максимальное значение прогресса. По умолчанию это `100`
- `prefix` (str)
    > Некоторое описание для полосы. Просто для понимания.
    >
    > Может быть пустым
- `bar_length` (int)
    > Длина полосы в символах. По умолчанию стоит `30` символов
- `bar_style` (str)
    > Дизайн полосы. По умолчанию стоит `line`
    >
    > Доступные дизайны: `line`, `points`, `blocks`, `arrow`.
- `frames` (bool)
    > Если активно, добавляет рамки к полосе. По умолчанию выключено (`False`)
- `show_ETA` (bool)
    > если активно, показывает ETA (Оценочное время завершения). По умолчанию активно (`True`)
> И имеет 4 метода:
- `update(value)`
    > Устанавливает значение прогресса. Значение должно быть целым числом
- `advance(step)`
    > Увеличивает прогресс на *n* шагов. Значение должно быть целым числом
- `stop()`
    > принудительно останавливает рисовку полосы и выходит.
- `finish()`
    > Устанавливает прогресс на 100% и выходит.

> Тут реализация такая же как и в `Status class`, просто аргументов больше.
>
> Я покажу только один пример реализации. Я надеюсь, вы поймете, как сделать по своему.
```python
with Progress(total=100, prefix="Какой-то юнит", bar_length=60) as bar:
    for i in range(100)
        bar.advance(1)
```
> Для примера я использую цикл "for", но вы должны использовать полезную нагрузку.


## `TUI` класс
> Предоставляет методы для рендера текстового интерфейса.
>
> сейчас класс не доделан и может вызывать ошибки. В следующих версиях постараюсь доработать логику.
>
> Итак, для использования, напишите
```python
from ttykit import TUI

ui = TUI(title="простой UI")
```
> Мы иничиализировали экземпляр, но сейчас меню пустое
>
> `TUI` получает строку для установки заголовка. В примере я установил "простой  UI" как заголовок.
>
> Первым делом покажу доступные методы:
- `addMenu(name, callback)`
    > Добавляет ваш пункт в меню.
    >
    > `name` - отображаемое название. Должен быть строкой.
    >
    > `callback` - ваша функция, которая будет вызвана, если пользователь выбрал ваш пункт.
    ```python
    def your_callback():
        pass

    ui.addMenu("Тестовый пункт", callback)
    ```
- `UpdateUI()`
    > Принудительно обновляет интерфейс.
    > 
    > Полезно, если вы добавили еще один пункт, во время работы интерфейса.
- `Run()`
    > Окей, мы добавили пункты в UI и настроили логику, но меню не показывается.
    > 
    > Для запуска меню, вызовите этот метод: он просчитывает логику и делает первый рендер UI.
> Пока что это все, что может делать класс, но в будущем сможет больше.
>
> Полный пример:
```python
from ttykit import TUI

def read();
    print("читаю")

def set_star():
    print("Звездочка выдана")

ui = TUI(title="простой UI")
ui.addMenu("Прочитать документацию", read)
ui.addmenu("Поставить звезду на репозиторий GitHub", set_star)

ui.Run()
```

## `Tree` класс
> Этот класс помогает вывести древовидную структуру в терминале
>
> Чтобы использовать, напишите (Сколько раз я это уже написал?)
```python
from ttykit import Tree

tree = Tree(label="Пример древа")
```
> Есть 2 метода:
- `add(label)`
    > добавляет ноду в структуру и возращает ее.
    >
    > Да, он использует копию этого же класса для создания ноды.
    ```python
    tree.add("pyproject.toml")
    tree.add("REAMDE.md")
    ...
    ```
    > И можете сделать "иерархию":
    ```python
    src = tree.add("src")
    src.add("__init__.py")
    src.add("main.py")
    ...
    ```
- `print()`
    > После того, как вы добавили все ноды в структуру, вызовите этот метод для вывода структуры.
> Это все. Класс не очень сложный, правда?
>
> Полный пример:
- `code`
    ```python
    from ttykit import Tree

    tree = Tree('Пример древа')
    tree.add("pyproject.toml")
    tree.add("README.md")
    src = tree.add("src")
    src.add("main.py")
    src.add("decorators.py")

    tree.print()
    ```
- `Output`
    ```text
    Пример древа
    ├── pyproject.toml
    ├── README.md
    └── src
        ├── main.py
        └── decorators.py
    ```

## `TaskState` класс
> Этот класс наследует `Enum` и предоставляет 4 переменные:
- `RUNNING`
    > возвращает код работы из Enum и имеет значение "running"

    > возвращает код успеха из Enum и имеет значение "success"
- `ERROR`
    > возвращает код ошибки из Enum и имеет значение "error"
- `WARNING`
    > возвращает код предепреждения из Enum и имеет значение "warning"
